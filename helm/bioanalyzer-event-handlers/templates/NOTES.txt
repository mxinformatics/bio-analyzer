9. Troubleshooting:

   If pods are not starting:
   - Check if all required secrets exist in the {{ .Release.Namespace }} namespace
   - Verify Azure authentication is properly configured
   - Check resource limits and node capacity

   If no messages are being processed:
   - Verify Service Bus connection and queue/topic names
   - Check Application Insights for any function execution errors
   - Ensure proper RBAC permissions if using Managed Identity

   Common issues:
   - ImagePullBackOff: Verify Docker image exists and is accessible
   - CrashLoopBackOff: Check application logs for startup errors
   - Authentication failures: Verify Azure credentials and permissions
